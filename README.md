 Predictive Maintenance of Induction Motor using Machine Learning (MATLAB)
 Overview
This project focuses on developing a **predictive maintenance system for an induction motor** using **machine learning techniques in MATLAB**. The goal is to predict potential motor failures in advance by analyzing operational parameters, thereby reducing unplanned downtime and maintenance costs.

The project includes **data preprocessing, model training, model comparison, and a MATLAB App Designer–based GUI** for visualization and analysis.

---

Features
- Machine learning–based fault prediction  
- Real industrial predictive maintenance dataset  
- Multiple model training and comparison  
- MATLAB App Designer GUI for user interaction  
- Performance evaluation using accuracy metrics  

---

Project Structure

---
 Dataset
- File: `ai4i2020.csv`
- Contains operational parameters such as temperature, torque, speed, and tool wear
- Includes failure labels for predictive maintenance analysis

---

 Methodology
1. Data preprocessing and normalization  
2. Feature selection and labeling  
3. Machine learning model training  
4. Model performance comparison  
5. Visualization using MATLAB GUI
